About — GitHub Repo Explorer

GitHub Repo Explorer · Version 269.26.3

A browser-native repository workspace built on the GitHub Git Data API. Single-file, zero-dependency architecture: atomic blob→tree→commit→ref transactions, encrypted local credential storage, an IndexedDB content-addressed cache, tabbed multi-pane navigation, and a full preview pipeline (image, animated SVG, audio, video, font specimens, text editing).

Author & maintainer: Henry Jayz (HenryCarm) — solo developer. Architecture, design and implementation.

Co-development: produced in collaboration with an AI engineering partner (Qwen), credited by request.
